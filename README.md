# Marvin Ridge Cricket Academy: Road to the Championship

FBLA 2026-2027 Computer Game & Simulation Programming. Fully offline cricket coaching game.

## Setup (one time, Mac and Windows)

1. Install **Python 3.12** from https://www.python.org/downloads/
   (Windows: tick "Add Python to PATH" in the installer.)
2. Get the project with GitHub Desktop (clone `fblaproject26-27`).
3. Open a terminal in the project folder, then make a private Python box:
   - Mac: `python3 -m venv .venv` then `source .venv/bin/activate`
   - Windows: `python -m venv .venv` then `.venv\Scripts\activate`
4. Install the game library: `pip install -r requirements.txt`

## Run the game

- Mac: `python3 main.py`
- Windows: `python main.py`

Press **ESC** any time to close the game.
